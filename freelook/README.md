# Freelook — mhv1 (Horizon)

Celibistrial'ın **Freelook** modunun Horizon (Minecraft 26.3, Rust) portu. Lisans: AGPL-3.0 (orijinal gibi, `LICENSE`).

## Kullanım
- **Sol Alt** (basılı tut): fare oyuncuyu değil kamerayı döndürür; karakter baktığı yöne bakmaya devam eder.
- Birinci / ikinci / üçüncü şahıs freelook tuşları (varsayılan atanmamış) Options > Mods > Freelook'tan atanır.
- **M**: Freelook ayarları.

## Ayarlar (`config/freeLook.json`, orijinal biçim)
- Hold / Toggle
- Default Perspective: First / Second / Third Person
- Head Rotation Limit: 360° (Full) veya 5°–300°
- Disabled Servers: listedeki sunucularda freelook kapalı (varsayılan `hypixel.net`). IP eklemek için "Add" dosyayı Not Defteri'nde açar; satırın yanındaki düğme siler.
